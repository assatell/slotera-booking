Bundled invoice PDF font
=========================

NotoSans-Slotera.ttf
  Family/version: Noto Sans Regular 2.015 (static hinted build)
  Source: https://github.com/notofonts/notofonts.github.io/tree/main/fonts/NotoSans/hinted/ttf

The font is distributed under the SIL Open Font License 1.1. The complete
license is included in OFL-1.1.txt. The static font replaces the 2 MB variable
font and is embedded into generated invoice PDFs
so the European scripts supported by Slotera (including Latin, Cyrillic and
Greek) do not depend on fonts installed on the PDF reader's device.

CJK-specific Noto Sans SC is intentionally not bundled because Chinese,
Japanese and Korean are not supported Slotera languages.
